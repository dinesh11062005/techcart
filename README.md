# 🛒 TechCart – Smart Mobiles & Gadgets Shopping Website

TechCart is a responsive shopping website for browsing and exploring smart mobiles, electronic gadgets, and accessories. The project is built using modern frontend technologies with a focus on a clean and user-friendly interface.

## 🚀 Features

* 📱 Browse mobiles and electronic gadgets
* 🛍️ Product shopping interface
* 🔍 Product-focused user interface
* 💰 Price calculation functionality
* 🎁 Random offer generation
* 🌙 Dark mode
* 🕒 Current time display
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **React.js**
* **Vite**

## 💻 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/dinesh11062005/techcart.git
```

### 2. Open the project

```bash
cd techcart
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

After running the command, Vite will provide a local URL similar to:

```text
http://localhost:5173
```

Open the URL in your browser.
